# ASSETRA

A professional NBFC loan management system monorepo with a Next.js frontend and Express backend.

## Structure

- frontend/
- backend/
- docs/

## Getting started

1. Copy environment samples and configure values.
2. Start PostgreSQL.
3. Install dependencies in both apps.
4. Run the backend and frontend on their respective ports.

## Default local addresses

- Frontend: http://localhost:3000
- Backend: http://localhost:5000

## Initial super admin

Set the environment variables in backend/.env before running the seed flow.
